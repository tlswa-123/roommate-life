# 合租生活管家 · Roommate Life

一个可直接访问的中文产品雏形，覆盖费用 AA、值日排班、公共物品和室友公约。

## 在线体验

https://tlswa-123.github.io/roommate-life/

## 功能

- 费用：新增账单、均分/权重分摊、结算建议与转账记录。
- 清洁：新增/分配任务、完成与撤销、轮值排班。
- 物品：登记、消耗、补货与低库存提醒。
- 公约：编辑条款、发起议题、室友表态。
- 概览：账单、任务、低库存和议题汇总。

## 数据与使用

演示数据保存在当前浏览器的 localStorage。无需登录；更换浏览器不会同步，多人实时协作尚未接入。本项目不含真实个人数据或凭据。

## 本地预览

使用任意静态服务器打开根目录即可。页面无第三方运行依赖，相对资源路径支持 GitHub Pages 子目录。

## 后续更新

在 main 分支更新网页文件，GitHub Pages 会重新发布。请保留仓库名和 Pages 地址。
